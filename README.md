# Dutyyy — тестовая версия системы нарядов

Приложение на FastAPI с исходными HTML шаблонами и CSS. Тестовый запуск использует пустую временную базу SQLite, которая может сбрасываться при перезапуске или повторном развертывании. Не вводите реальные персональные данные.

## Локальный запуск

```bash
python -m venv .venv
. .venv/bin/activate
pip install -r artifacts/duty-scheduler/requirements.txt
cd artifacts/duty-scheduler
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Откройте `/dashboard`. Проверка работоспособности: `/health`.

## Railway

Создайте отдельный сервис из этого репозитория с корнем `/`. Dockerfile задаёт установку зависимостей и запуск на переменной `PORT`. Путь к тестовой базе по умолчанию: `/tmp/dutyyy-demo.db`. Данные временные и общие для посетителей тестового сайта; используйте вымышленные записи.
